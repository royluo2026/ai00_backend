Decision: raw TC business return values travel in bounded JSON strings and typed field entries, keeping governed envelopes closed while allowing fields to evolve. No credentials or transport secrets enter cache. Cloud batches never masquerade as personal observations. New capabilities stay experimental until independently approved/runtime verified.

The existing property projection discarded distinct BOMLine/ItemRevision values and empty strings before upload. A new Simulation-owned `simulation.teamcenter.model_cache.read@1` / native `teamcenter.model_cache.read@1` wraps reused children traversal and reads the same fixed TC business-property allowlist, preserving object UID, field name, JSON value and read state in `raw_fields`. Existing @1 children/property contracts are unchanged. Every wrapped read returns the verified TC principal hash; durable batches additionally pin the Connector device. Admission and results are fenced by task/attempt/operation identity. TC timeout cleanup includes the new atom and retains the existing 600-second large-tree budget.

Batch indexes page through all history. Node query pages use a byte budget, return actual next cursors and retain single long values intact. UI pagination remembers actual cursors. No-filter reads use SQL paging; filtered reads and final graph validation stream large property bags instead of buffering the full batch.
