# 06 磁盘监控、状态栏与文件生命周期

PLMXML/VF场景文档、派生结果文件计入AI00场景/业务数据；待提交包计可靠暂存；仅用户明确归档的JT/VFZ依赖包归入长期模型。FCC仍独立计量。详见[10](10-plmxml-environment-persistence.md)。

本条已由用户明确要求纳入改造。当前仅完成状态栏入口核查，尚未实现容量监控。以下是可以单独评审和交付的规格。

## 1. 分类与所有权

| 类别 | 内容 | 默认清理权 |
|---|---|---|
| AI00 长期保留数模 | 用户经 App 明确保存／归档的模型及清单 | 用户明确管理，不自动按普通 LRU 删除 |
| AI00 缩略图 | 已授权的工艺卡缩略图 | 容量上限及闲置淘汰 |
| AI00 工作集 | SQLite 投影、布局、映射及必要索引 | 失效 scope／缓存策略；草稿不得混删 |
| AI00 待交付结果 | 尚未完成上传／登记／回填的截图 | 不参加普通缓存淘汰 |
| AI00 临时输出 | 可重建导出、中间文件、已释放显示临时文件 | 到期、任务结束或确认可重建 |
| VisMockup/FCC 整文件 | 原生管理完整文件缓存 | 仅 Siemens 受支持机制 |
| VisMockup/FCC 分段与索引 | fms.seg／extent／元数据等 | 同上 |
| 其他本地占用 | 日志、语音资源、通用浏览器缓存等 | 单独策略，不能冒充数模 |

普通打开 JT 不产生长期保留记录。持久模型必须有保存动作、主体、来源／版本、文件清单、摘要和保留用途。监控不擅自搬迁或删除当前已有模型缓存；旧文件先盘点分类并提示待迁移。

## 2. 展示

状态栏固定为 `本地占用 <总量> | AI00 <小计> | VisMockup/FCC <小计>`。窄窗口可缩写但不能把两者合并为一个“缓存”。本地占用明确定义统计范围，若其他占用未纳入总量必须标注“已纳管范围”，不能声称全机总占用。

悬浮／键盘聚焦显示向上展开明细；点击可固定详情面板，支持复制统计摘要、手动刷新和定位到安全管理页。不得把任意目录路径作为 Renderer IPC 输入。

详情含分类字节、文件数（若可得）、归属、统计根目录／磁盘、最后更新时间、口径、完整性、错误、相关磁盘剩余空间、长期保留与可回收的区别。普通状态不弹阻断对话框。

总量未知时显示“部分统计，已知 …”，未知项显示“未知”及原因；目录不存在但已确认是有效未创建目录时可以零；路径未发现或无权限不能零。FCC 离线只表示服务状态，不让目录字节归零。

## 3. 统计口径

首先确定各类目录的真实所有权，拒绝重叠目录重复求和。开发、测试、生产及账号 scope 不能互相冒名。FCC 根目录来自有效配置或受支持状态；模板示例只是候选。

逻辑大小和实际磁盘分配大小分开；稀疏、预分配、压缩及硬链接会导致差异。能取得本卷稳定文件身份时按卷＋文件 ID 去重，不读取几十 GB 内容求哈希来统计容量。

分类中同一物理文件被多类引用时标为共享，分配到一个主类并列引用，不能让分类小计和总计不明原因不一致。跨盘实际复制是两份占用，不能按相同内容摘要减掉第二份。

不跟随目录联接／符号链接递归越界；命中可确认受控映射时另作为独立根。仅统计元数据，不打开 JT 内容、凭据、FCC 内部数据库或私有业务文档。

## 4. 后台执行

统计在 Electron Main 的后台 worker／等效非 UI 线程执行，单飞、可取消、有时间预算和节流；结果缓存，悬浮不发起递归扫描。自己的文件写入更新索引，周期性对账处理外部删除和原生缓存变化。

建议初始调度：App 空闲后首次扫描；普通定期扫描间隔 5 分钟；用户手动刷新最短间隔 30 秒；扫描超时按部分结果返回并限频续扫。均为待设备实测的初始参数，不影响应用打开和截图。详情打开不提高到持续全盘扫描。

一次扫描出现目录变化时标 approximate／partial；不持有文件锁来追求瞬时精确。数据包带 `scan_id, sampled_at, duration, metric_kind, complete, categories, volumes, errors`，错误不包含密钥／文件内容。

## 5. 提醒策略

容量上限是各所有者策略，不统一删除。状态至少有正常、接近配置配额、磁盘不足、待交付积压、统计过期／失败。建议低空间初值为相关卷可用量低于 max(10 GiB, 卷容量 5%)，须通过用户设备预算评审；同一低空间事件去重，不每次扫描通知。

空间不足先暂停新截图／新显式保存，保持已有结果，提供受支持清理入口。AI00 不调用 FCC purge 作为自动兜底；共享 FCC 的配置／重启／清理需明确操作范围和授权。

## 6. 接口与安全

本机只读监控可复用既有可信 Main IPC；设计候选为 `getLocalStorageUsage()` 无路径参数、只读返回规范分类。是否纳入业务能力按实际副作用及治理归属判断，不凭新增函数就新建 Capability。

长期模型保存／删除是独立业务动作，有资源范围、确认、幂等、在用引用检查及审计，不能藏在只读统计接口里。普通缩略图淘汰也不能波及草稿或待交付结果。

浏览器端不能读取本机磁盘；显示当前端不支持或隐藏桌面指标，不用云端磁盘容量冒充用户电脑。

## 7. 验收

构造重叠目录、硬链接、跨盘副本、稀疏文件、符号链接、无权限目录、空目录、扫描期间删除、FCC Offline、用户明确保存模型、待上传 PNG、超大目录及窄窗口／键盘访问。核对总量口径、分类不串、未知不归零、主线程无阻塞、无自动删除原生文件。
