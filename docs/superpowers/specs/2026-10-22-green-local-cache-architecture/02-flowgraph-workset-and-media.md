# 02 流程图、本地工作集、多人同步与图片

## 1. 打开契约

桌面读路径：认证及资源选择 → SQLite 已同步工作集 → 当前可视区域结构／已有布局 → 缩略图 → 后台云端增量追平。无工作集时云端首屏优先，不等待全量图片、知识、规则及模型关联。

界面明确 `cached_at / source_revision / freshness / sync_state`，不能显示旧数据却宣称最新。无未提交修改的安全差异可增量应用；存在本地修改时保留草稿并显示冲突，不突然重置缩放和选中项。

首屏目标：已缓存目标线体从点击到可操作 p95 ≤ 1 秒；这是待基准验证目标。记录数据量、机器、冷热状态和样本，不将“空壳页面出现”当可操作。页面切回保留视图状态。

## 2. 业务结构、语义和布局

业务工序稳定身份不等于视图节点 ID。一个工序可以出现在多个视图；卡片位置与执行顺序分开。连接线分业务语义线和纯展示线，不能仅凭拖线就悄悄重写工艺关系。

线体／工位归属、父子关系与工序顺序需要事务维护：旧父移除与新父插入、排序、引用影响和变更序号同次提交。移动工序保留业务身份。并发移动／删除父节点必须发生冲突或按明确契约处理，不能制造双重归属。

GBOP 关联保存 `standard_definition_ref + version + mapping evidence`。标准库不完善允许未标准化；不靠临时数字编码永久连表。同标准码在多个工位的工序分别有实例身份。

## 3. SQLite 本地表的职责

逻辑集合：`workset_scope`、`entity_projection`、`relation_projection`、`diagram_layout`、`sync_cursor`、`pending_change`、`thumbnail_index`。实际合并与分表服从现有实现和访问测量，不每域复制全部数据库。

工作集键至少带服务来源、租户、主体访问范围、项目／BOP、版本和投影 schema 版本。登出或主体变化不复用旧权限结果。SQLite 写入单入口、事务更新投影和 cursor；大投影分批处理但只有完整 generation 可激活。

本地草稿允许落盘，云端才确认正式版本。离线编辑范围第一阶段仅限可明确记录的工艺内容／布局草稿；跨域冻结、正式回填和无法验证引用的结构发布要求在线。上传草稿做 expected revision 检查，不设无限自动重试。

## 4. 同步协议

输入：固定 scope、投影版本、已确认 cursor、分页上限。返回：变更序列、实体版本／墓碑、依赖范围、下一 cursor、服务端水位及是否需要重建。

规则：

1. 同 scope 的 cursor 单调推进；重复页幂等；乱序页不推进水位。
2. 初次分页固定 generation；中途源变化不能静默混页。
3. 墓碑保留到足以识别失效关系；不靠返回列表里“没出现”推断已删除。
4. cursor 过期时只重建目标工作集；新 generation 准备好后切换，旧工作集继续可读但标记未追平。
5. 不同端同一 mutation_id 重发返回原结果；同 key 不同内容拒绝。
6. 云端授权撤回后立即停止写入及受保护资源读取，处理本地数据可访问性；磁盘已有字节不授予访问权。

可复用现有变更时间／版本能力时先复用；没有可靠增量序列前以固定版本分页为保守起点，不假装 timestamp polling 不会漏更新。

## 5. 渲染预算

只渲染可视区域加小缓冲，索引支持节点定位、连线边界及搜索。读取工序详情、知识、问题和产品绑定按需发生，不阻塞总览。布局版本已经保存则直接使用；布局算法只在明确需要时运行并保存结果。

量测分别包含网络、反序列化、SQLite、投影组装、布局、DOM／canvas、首图。目标数据集分小线体、中线体、整项目；阈值实测锁定，不凭固定全量遍历兜底。

## 6. 缩略图与原图

缩略图键：`source + authorized_scope + attachment_id + content_version/digest + width/height + transform_version`。临时 URL 只作为一次获取地址，刷新 URL 不生成新逻辑图片；内容变化生成新键。

优先复用已授权服务端缩略图，缺失时由附件归属服务生成并返回正式媒体版本。不得要求下载每张原图后才生成首屏缩略图。需要确认现有附件服务的缩略图能力、尺寸和认证方式，缺失列为实现项。

原图点击后在线获取，用于短期显示，不纳入 AI00 长期原图库。HTTP／浏览器临时缓存受平台机制影响，不承诺绝对零临时字节。关闭显示时释放 App 持有的 object URL／临时租约；控制端点缓存策略及临时文件生命周期。

缓存下载：去重正在下载请求、有界并发、校验版本和媒体类型、临时文件完成后原子入索引。失败占位不阻塞卡片，后台有限重试；过期 URL 重新请求授权地址，不换成其他工序图片。不同账号不共享授权状态。

## 7. 结果适用性

图片附件关系仍在云端 BOP 所属域。流程图通过正式投影同步更新；仿真页不能直接修改卡片私有 JSON。图片携带运行输入依赖，变化后可标记历史／待重做，不能自动删除。

布局变化不让截图失效；工艺文字变化是否影响截图或工艺卡输出由结果类型定义。零件／绑定／模型变化只影响相关结果，不能简单整线清空。

## 8. 关键场景

两人改不同布局可保存不同视图；改同工序内容 CAS 冲突；移动工序和删除父工位冲突；上传附件不覆盖他人文字；缓存可读但离线不宣称云端已保存；同步期间用户浏览位置不跳动。
