# 05 冻结基线、多阶段比较与绑定迁移

## 1. 基线内容与语义

BaselineManifest 固定引用项目阶段、BOP 结构／内容版本、流程图视图版本、TC 配置与实际数模快照、模型集合、绑定版本、场景版本，以及知识／标准工序／规则的引用版本。检查结论另存，记录其输入，不把规则定义和检查结果混成一个版本。

标签 TG0／TG1 可以显示或另命名，但不可变 baseline_id 和封存摘要才是身份。同一标签是否可有多次封存由项目所有者定义，不能覆盖旧 baseline_id。

冻结不等于把整个 SQLite、原生内存和所有 JT 压缩一份。模型字节的长期归档单独选择，普通 FCC 缓存可淘汰。

## 2. 冻结协议

1. 创建 freeze request，固定 scope、业务版本、目标标签和幂等身份。
2. 获取各域不可变引用及其完整性／权限凭据；有原生临时修改时先保存工作场景差异或明确排除，不能冻结未说明的内存状态。
3. TC 解析或复用已确认固定快照，记录日期条件及解析一致性证据。
4. 校验绑定端点、跨集合关系、BOP 与模型版本组合；缺失显式列入 completeness，不用补假实例通过。
5. 提交前验证相关依赖仍符合约定；对跨域引用采用准备／确认流程，不宣称单一分布式事务。
6. 由基线所有者事务提交 manifest 及封存摘要，重复请求返回同一结果。

原生操作失败、上传未完成、检查失败和未标准化工序不自动互相等价。项目策略可以允许带问题的阶段冻结，但问题和未完成结果不可隐去。是否允许带未验证一致性的快照成为正式审计基线是治理决策，不由客户端暗定。

## 3. 派生与源升级

派生保留 parent baseline／workspace revision；未变化对象继续引用。源 BOP 更新或 TC 新配置不自动升级已有仿真引用。升级产生差异草稿、绑定迁移结果和新工作版本。

跨阶段稳定对应先基于可信工程身份和上下文。实例删除、换父、复用、包装层变化、原生辅助几何节点均需区分。名称／几何相似提供候选及置信证据，不自动把未确认候选变正式关联。

## 4. 同文档多集合

ComparisonRevision 固定左右 baseline/snapshot/model_set、对齐方案、对应关系版本、比较算法版本、过滤与显示配置。

原生文档可包含多套集合：TG0、TG1、用户插入集合。每个有独立集合根及成员映射；共享 JT 内容不共享实例身份／颜色／绑定。若原生不支持可靠集合身份，必须在接入门验证受支持的标记／容器方式，不能只靠树上显示名称。

比较对齐矩阵以集合为单位，不能改来源矩阵；同一快照在同文档插入两份也必须可区分。过滤比较结果不改变冻结成员。

## 5. 差异分类

| 类型 | 判断依据 | 典型工艺影响 |
|---|---|---|
| 新增／删除实例 | 配置实例集合 | 需求覆盖、绑定缺失 |
| 工程换版／换件 | 可信 revision／part identity | 关联适用性与截图检查 |
| 表示变化 | 精确文件／几何表示版本 | 原截图是否需更新 |
| 装配结构变化 | 父子路径／归属 | 实例继承、工位范围 |
| 空间变化 | 同坐标规范下来源姿态 | 装配顺序、干涉、视图 |
| 工艺变化 | 工位、工序、操作／需求版本 | 执行计划与规则 |
| 绑定变化 | 端点／映射及证据版本 | 截图与工艺适用性 |
| 显示变化 | 布局或比较对齐 | 通常不让几何结果失效 |

精确装配和非精确装配、不同布局／packing 模式需要在 TC 接入时记录，否则实例数量变化可能只是表达差异，不能误报工程变更。

## 6. 对比工作流

流程图选择 TG0/TG1 → 读取各自固定工艺投影 → 生成差异 → 在原生打开两个集合 → 用户明确对齐 → 点击变化联动两边工序与实例 → 保存分析场景。

反向选原生实例，先确认集合，再列该阶段工序。重复绑定展示所有相关候选，不随意跳一条。

“TG0 工艺适配 TG1 产品”派生新分析场景，记录组合来源和未确认迁移项；不覆盖 TG0／TG1 的原始绑定。

## 7. 可恢复性

独立记录 manifest 可读、TC 依赖可获取、归档完整、原生可打开、业务绑定可执行五个状态。缓存缺失可重新获取不是历史丢失；TC 文件不可获取又无归档时，明确缺失清单，不用新文件替换旧文件冒充恢复。

归档必须用户明确发起，空间估计与保存范围可见，进入 AI00 长期保留数模分类。数据权限与跨阶段访问仍逐项验证。

## 8. 验收

两个阶段引用同文件不同实例位置；两次插入相同快照；同名不同件；父移动对子世界矩阵影响；规则名不变内容变化；原生辅助节点不计入工程新增；历史文件丢失；源升级时旧绑定不变；比较对齐不修改基线；含问题基线与完整基线能明确区分。
