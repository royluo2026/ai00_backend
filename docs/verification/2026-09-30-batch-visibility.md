# Parent visibility uses one native batch

The user observed loaded models disappearing or appearing one at a time when clicking a parent. `ExecuteViewerNodeAsync` iterated the mapped geometry keys and called `SetNodeVisible` for every occurrence. Each call created a single-node native list, dispatched SetNodesVisible/SetNodesInVisible and refreshed the view. The logical command was one parent action, but the native display commands and refreshes were per part.

The shared document adapter now builds the complete validated native node list before dispatch, calls the native visibility command once, then refreshes once. It checks the active document again before dispatch. A single-part action uses the same interface with one key. Existing per-occurrence identity checks, visibility readback and unknown-outcome handling remain. Document-wide hiding retains AllNodesOff. Cached assembly replacement and rollback also restore previously hidden occurrences as one batch. Logs record target_count and visibility_dispatch for parent actions. There are no new dependencies or Capability schema changes.

The cached-parent regression first failed because there was no batch call. It now asserts one two-occurrence batch for parent show/hide and a one-occurrence batch for a part; the sibling and parent mixed-state assertions remain. 99 relevant Connector tests passed, including document-switch, stale mapping, failure/outcome, pipe and cache-environment checks. The self-contained Debug publish succeeded. Git diff whitespace checks passed.

A disposable native VisMockup document with 39 real positioned occurrences verified the documented CreateNodeList / AppendNode / SetNodesVisible or SetNodesInVisible / UpdateView sequence. One parent hide took 145.68 ms; one parent show took 136.33 ms, including constructing the list. Each used one native visibility command and one refresh. Showing only one part left 38 hidden; hiding one part left 38 visible. All 39 world matrices remained unchanged. These are this sample's measurements, not a guarantee for every assembly or cold JT load. The test document was closed and the previous active document restored. Evidence: workspace `.runtime/batch-visibility-native-proof.json`.
